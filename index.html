Data Center Mechanical Design Kickoff

A document-led mechanical engineering workspace. Upload architect / owner deliverables, extract searchable text and schedules in your browser, review suggested values, then build a traceable mechanical design basis, load model, system strategy and coordination register.
Version 1.0.0  ·  Last updated 11 November 2026
Important: “Auto-populate” means local document text extraction plus rule-based candidate detection. Every extracted value is an unverified proposal until a mechanical engineer confirms it. This tool is not a substitute for BIM authoring, load calculations, code analysis, vendor selection or professional engineering review.
Privacy & storage: Documents are extracted locally in your browser — they are not uploaded to a server. The only external requests are loading the PDF / Word / Excel reader libraries from cdnjs.cloudflare.com when needed (see README for the full list). “Save project locally” uses this browser’s local storage only. It is not a shared project database: data saved by one person on one browser/device is not automatically visible to anyone else. Use Export (JSON/CSV) to share a project file.

Architect / owner document intake

Select files or drag them into the drop zone. Supported extraction: PDF, DOCX, XLSX, XLS, CSV, TXT, and text-based IFC. For RVT, DWG, point clouds and scanned PDFs, export schedules / views to PDF, XLSX, CSV, IFC or searchable PDF first. Files are processed in this browser session; they are not uploaded to a server.
